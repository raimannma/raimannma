## 💼 Freelance: ClickHouse
I'm open to **freelance ClickHouse work**. Things I can help with:

- Schema & table engine design (MergeTree family, partitioning, ORDER BY / primary key choice)
- Query and performance tuning: slow queries, PREWHERE, skipping indexes, projections, materialized views
- Ingestion pipelines and Rust/Python services on top of ClickHouse
- Migrations from Postgres or other databases to ClickHouse

What I bring:
- Running ClickHouse in production as the analytics backend of the [Deadlock API](https://github.com/deadlock-api/deadlock-api)
- Contributing to [ClickHouse core](https://github.com/ClickHouse/ClickHouse/pulls?q=is%3Apr+author%3Araimannma) (query execution, index analysis, type handling)
- [clickhouse-antlr4](https://github.com/raimannma/clickhouse-antlr4): an ANTLR4 grammar for ClickHouse SQL

📩 Interested? Email me at <a href="mailto:raimannma@outlook.de?subject=ClickHouse%20freelance%20inquiry">raimannma@outlook.de</a>.
